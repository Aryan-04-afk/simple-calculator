# Simple Calculator

A small command-line calculator written in Python, used to demonstrate Git branching, merging and merge-conflict resolution.

## Features
- Addition, subtraction, multiplication, division
- Divide-by-zero handling

## Usage
```bash
python3 calc.py
```
Example:
```
> 4 + 5
= 9.0
```

## Running tests
```bash
python3 -m unittest -v
```
